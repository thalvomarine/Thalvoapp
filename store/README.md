# Store package

Paste-ready materials for App Store Connect and Google Play Console.

| File | Use |
| --- | --- |
| `listing.tr.md` / `listing.en.md` | Name, subtitle, description, keywords |
| `apple-app-privacy.md` | App Privacy questionnaire |
| `google-data-safety.md` | Play Data safety form |
| `review-notes.md` | Reviewer notes (payments simulated) |
| `assets/` | `icon-512.png`, `icon-1024.png`, `feature-graphic.png` |
| `assets/screenshots/` | Drop device captures here before submit |

Full process: [`docs/STORE_LAUNCH.md`](../docs/STORE_LAUNCH.md)

```bash
npm run store:assets
npm run store:preflight
```
