# Google Play Data safety form

Privacy policy URL: https://thalvo.org/privacy  
App collects user data: **Yes** (for signed-in features)  
Data encrypted in transit: **Yes** (HTTPS)  
Users can request deletion: **Yes** — in the app: Profile → Account settings → Delete account (`delete_own_account`). Also https://thalvo.org/privacy and support@thalvo.org.

## Collected data

| Category | Data types | Collected | Shared | Mandatory | Purpose |
| --- | --- | --- | --- | --- | --- |
| Location | Approximate, Precise | Yes (when permitted) | No third parties for ads | No (runtime permission) | App functionality |
| Personal info | Name, Email, Phone | Yes (account) | No ads | Yes for account features | Account management |
| Photos / videos | Photos | Yes (user-chosen) | No ads | No | App functionality |
| App activity | In-app actions / messages as needed for jobs | Yes | No ads | Yes for those features | App functionality |
| Financial info | Purchase history (simulated ledger only) | Yes | No | No | App functionality |
| Device / other IDs | App instance / account id | Yes | No ads | Yes | App functionality |

## Not collected / not used

- Advertising ID / ads SDK: **No**
- Web browsing history: **No**
- Approximate location for ads: **No**

## Security practices

- Data encrypted in transit: Yes  
- Independent security review: No (unless you commission one)  
- Committed to Play Families Policy: No (not a kids app)
